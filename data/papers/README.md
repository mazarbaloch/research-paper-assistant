# Add your papers here

Place legally obtained research-paper PDFs in this folder (subfolders also work), then run
`uv run python ingest.py` from the project root. PDF files are ignored by Git.

Use real papers you have permission to process. Do not commit commercial publisher PDFs
unless their redistribution license explicitly allows it. No sample research text is bundled.

Scanned PDFs need OCR before ingestion. Page citations use the original PDF's one-based
page positions, which can differ from the printed page labels. Keep the PDFs here to enable
original-file downloads in the application.
